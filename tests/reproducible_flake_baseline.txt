#
# Fixed nodes: `# fixed-at: <UTC timestamp> <node id>` retires only that
# node's failure evidence recorded at or before the instant its fix landed.
# It does not touch any other node's evidence or the gate's bar for new
# flakes, and a failure of the same node recorded after the timestamp is
# ordinary live evidence again. A preceding comment should name the bead and
# the commit that fixed the node, the same convention the node-id entries
# below already use.
#
# Known limitation: a workspace testing a stale (pre-fix) tree can still
# write a failure record after the declared fix instant, since the record's
# timestamp reflects when it ran, not what tree it tested. Such a failure is
# not retired and the gate goes red rather than silently staying green; this
# is a transient red that self-heals as workspaces rebase and as records age
# out at `RETENTION_DAYS`, not the permanent evidence this directive exists
# to remove.
