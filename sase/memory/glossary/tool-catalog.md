---
keyword: Tool Catalog
---

The Tool Catalog is the set of named tools (`check`, `test`, ...) declared under
`tools:` in the [[glossary:current-project]]'s own `sase/sase.yml`. Entries are complete
argv definitions that user, machine, plugin, and builtin config layers cannot alter.
`sase tool list` shows them; each execution becomes a [[glossary:tool-run]].
