An agent data card block is one titled, stably identified unit inside an
[[glossary:agent-data-card]] (deck -> card -> block); blocks are optional and never
nest. A session Reply card holds one block per concrete [[glossary:sase-turn]], landing
on the newest block, with `[` / `]` stepping between blocks and a one-row block rail
timeline.
