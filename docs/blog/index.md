# SASE Blog

The SASE Blog is the publishing surface for essays about Structured Agentic Software Engineering (SASE): durable work
units, orchestration, provider-independent workflows, review state, and the coordination layer around coding agents.

## Start Here

The [SASE Blog Series](../series/agentic-software-engineering.md) has ten posts:

1. [\[00\] Why Coding Agents Need Orchestration](posts/why-coding-agents-need-orchestration.md) — the launch essay on
   _why_ coding-agent work needs durable orchestration around plans, state, review, dependencies, retries, and handoff.
2. [\[01\] Hello, SASE — Your First 15 Minutes Orchestrating Coding Agents](posts/hello-sase-your-first-15-minutes.md) —
   the hands-on follow-up: install, launch an agent, find the result in ACE, and learn the names of every major
   component.
3. [\[02\] XPrompts in Depth — From One File to Full Workflows](posts/xprompts-in-depth.md) — when a single Markdown
   file is the right shape, when typed inputs and directives are enough, and when YAML workflows earn their existence.
4. [\[03\] AXE — The Background Daemon That Keeps Agent Work Moving](posts/axe-background-daemon.md) — the
   orchestrator/lumberjack/chop architecture, default cadences, `%wait` resolution, and maintenance mode.
5. [\[04\] Beads and SDD — Planning Multi-Agent Work That Actually Lands](posts/beads-and-sdd.md) — tales, epics,
   legends, the bead data model, and how `sase bead work` turns a plan into a fleet.
6. [\[05\] Commit Workflows — The Pluggable Path From Diff to PR](posts/commit-workflows-plugins.md) — `#commit`,
   `#propose`, `#pr`, the commit-finalizer contract, runtime-uniform skills, and the VCS provider boundary.
7. [\[06\] ChangeSpecs in Practice — Review State Outside the Chat](posts/changespecs-in-practice.md) — the `.sase`
   record end to end, commits drawers, mentor execution, HOOKS prefixes, and the ACE keystrokes that drive review.
8. [\[07\] Driving SASE From Your Phone — Telegram as the Mobile Control Surface](posts/telegram-mobile-agents.md) — the
   sase-telegram chop: activity-aware notifications, plan approvals from inline keyboards, launching agents and
   reviewing generated images from the chat.
9. [\[08\] Where You Type — The Prompt Input Widget and sase-nvim](posts/prompt-widget-and-nvim.md) — the multiline
   Textual widget that drives most launches, and the Neovim plugin that gives the same prompt language a richer editor.
10. [\[09\] What's Next — Shared Memory, Mobile, and the Web Surface](posts/whats-next-memory-mobile-web.md) — the three
    horizons SASE is reaching for next, and why each one isn't shipping yet.

[00] and [01] are the why/how pair; [02]-[08] deepen one subsystem at a time and can be read independently; [09] looks
forward.
