# SASE Blog

The SASE Blog is the publishing surface for essays about Structured Agentic Software Engineering
(SASE): durable work units, orchestration, provider-independent workflows, review state, and the
coordination layer around coding agents.

## Start Here

Start with
[SASE: Structured Agentic Software Engineering](posts/structured-agentic-software-engineering.md),
the launch post: why SASE wraps agent CLIs, how XPrompts work, what the ACE Agents tab changes, and
how to install the tool.

If you want the practical path first, use
[Getting Started: Your First 15 Minutes](../getting_started.md): install, provider readiness, a safe
first run, and the first visible agent record.

More posts are in the repository as drafts and will be published over time. The generated archive
below lists only the entries included in the public site.
