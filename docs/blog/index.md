# SASE Blog

The SASE Blog is the canonical publishing surface for essays about structured agentic software engineering: durable work
units, orchestration, provider-independent workflows, review state, and the coordination layer around coding agents.

## Start With The Launch Series

The [Agentic Software Engineering series](../series/agentic-software-engineering.md) introduces the ideas behind SASE in
order. Start with [Why Coding Agents Need Orchestration](posts/why-coding-agents-need-orchestration.md), then use the
series hub to follow the planned posts as they are published.
