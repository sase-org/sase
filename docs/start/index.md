# Get started with SASE

These pages take you from installing SASE to running and reviewing work in its demo
workspace.

## Is SASE for you?

SASE coordinates coding-agent work through a command-line tool and terminal interface.
It is alpha software, so its interfaces and workflows are still evolving. SASE is for
people who want to supervise agents working in separate Git workspaces; it does not
replace the coding-agent CLI you use.

You need Linux or macOS, Python 3.12 or newer, [`uv`](https://docs.astral.sh/uv/), Git,
and one supported agent CLI that is installed and authenticated. The first lesson
includes links for provider setup.

## Start with these lessons

- [Install and set up SASE](install.md) — install the command-line tool and check your
  provider, about 5 minutes plus provider setup if needed.
- [Run your first agent](first-run.md) — launch a read-only request in the demo
  workspace and inspect the result, about 5 minutes plus model time.
- [Make and review a change](first-change.md) — ask an agent to make one small edit and
  inspect the resulting diff, about 5 minutes plus model time.
