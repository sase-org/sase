# Guides

Each guide solves one goal. Pick the goal that matches what you want to do.

## Set up

- [Add an existing repository](add-existing-repository.md) — work in a repository you
  already have.
- [Choose providers and models](choose-providers-models.md) — ready one provider and
  pick the model agents use.
- [Configure the essentials](configure-essentials.md) — set the values most setups
  change.
- [Set up shell completion and your editor](setup-completion-editor.md) — complete
  commands with `<TAB>` and edit prompts with assistance.

## Plan and automate

- [Plan a multi-agent change](plan-multi-agent-change.md) — decompose large work into
  reviewed phases.
- [Schedule recurring work](schedule-recurring-work.md) — run a check on a schedule.
- [Get automated code review](get-automated-code-review.md) — review each change
  automatically.

## Fix problems

- [Diagnose problems with sase doctor](diagnose-with-doctor.md) — run the read-only
  checks first.
- [Unstick a queued agent](unstick-queued-agent.md) — clear capacity waits and holds.
- [Recover an interrupted agent](recover-interrupted-agent.md) — restart, resume, or
  revive a broken run.
