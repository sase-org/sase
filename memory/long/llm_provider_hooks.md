# LLM Provider Hooks

This repo configures the sase_sibling_commit_stop_hook stop hook for agents that run on the sase repo (i.e. sase
development) and configure the sase_commit_stop_hook globally (i.e. it should run regardless of what project directory a
sase agent is run from). Pointers to hooks documentation for some of the LLM providers that sase supports can be found
below:

**Codex Hook Documentation**  
The memory/long/llm_provider_hooks/codex.md file contains qwen code's hook documentation.

**Qwen Code Hook Documentation**  
The https://qwenlm.github.io/qwen-code-docs/en/users/features/hooks/ URL contains qwen code's hook documentation.
